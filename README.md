# 🌸 Нежность — Цветочный магазин

![Deploy](https://github.com/snezhnayaa/flower-shop-nezhnost/actions/workflows/deploy.yml/badge.svg)

Современный адаптивный одностраничный сайт цветочного магазина «Нежность».

## Описание

Лендинг создан в рамках лабораторной работы №4 (Информатика) с использованием современных технологий генеративного ИИ (LLM).

**Тема:** Уютный цветочный магазин в Санкт-Петербурге с доставкой букетов.

## Структура сайта

1. **Header** — sticky-навигация с логотипом
2. **Hero** — главный экран со слоганом «Цветы, которые говорят за вас»
3. **О нас** — история магазина и преимущества
4. **Каталог букетов** — 6 популярных композиций
5. **Акции** — 3 текущих предложения
6. **Бонусная программа** — «Цветочные бонусы»
7. **Контакты** — адрес, часы работы, соцсети
8. **Footer**

## Технологии

- Чистый HTML5 + CSS3 (без фреймворков)
- Адаптивный дизайн
- Плавная прокрутка
- Hover-эффекты и анимации
- Семантическая разметка

## Цветовая палитра

- Кремовый: `#FDF8F5`

## Как открыть

1. Откройте `index.html` в браузере
2. Или используйте Live Server в VS Code
